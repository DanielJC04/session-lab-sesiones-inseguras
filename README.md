# Session Lab

Minijuego educativo sobre secuestro de sesión web. Incluye diez preguntas con
cuatro opciones (A-D), tres vidas, puntuación, y los comodines 50/50 y escudo
(un uso por partida). El 50/50 elimina dos opciones incorrectas y deja dos
respuestas posibles. Cada pregunta tiene 15 segundos; si se acaba el tiempo,
se pierde una vida y avanza automáticamente. El escudo activado antes de
responder protege de un error sin sumar puntos ni restar vidas, y avanza a la
siguiente pregunta.
El juego corre en el navegador y no necesita dependencias ni compilación.

## Ejecutar localmente

Abre `index.html` en un navegador.

## Publicar en Render

El archivo `render.yaml` configura un sitio estático gratuito que publica la
raíz de este repositorio. En Render, crea un **Blueprint** y conecta este
repositorio de GitHub. Render detectará la configuración y desplegará el juego
automáticamente después de confirmar el servicio.

## Uso de IA generativa

Se utilizó IA generativa como apoyo para diseñar e implementar las mecánicas
del concurso y preparar la publicación en Render. El juego no requiere
servicios de IA externos.
