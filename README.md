# Session Lab

Minijuego educativo sobre secuestro de sesión web. Incluye seis preguntas,
tres vidas, puntuación, los comodines 50/50 y escudo (un uso por partida), y un
temporizador de 15 segundos por pregunta. El tiempo agotado resta una vida y
avanza solo; el escudo activado antes de responder protege de una respuesta
incorrecta sin sumar puntos ni restar vidas, y avanza a la siguiente pregunta.
Se ejecuta
directamente en el navegador; no necesita dependencias ni compilación.

## Ejecutar localmente

Abre `index.html` en un navegador.

## Publicar en Render

El archivo `render.yaml` configura un sitio estático gratuito que publica la
raíz de este repositorio. En Render, crea un **Blueprint** y conecta este
repositorio de GitHub. Render detectará la configuración y desplegará el juego
automáticamente después de confirmar el servicio.

## Uso de IA generativa

Se utilizó IA generativa como apoyo para diseñar e implementar las mecánicas
del concurso y preparar la publicación en Render. El juego no requiere
servicios de IA externos.
